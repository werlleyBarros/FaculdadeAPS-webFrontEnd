# FaculdadeAPS-webFrontEnd
Unicarioca Atividade pratica supersionada - WebFrontEnd Professor Lucas Romao

Este repositório contém o front-end de uma aplicação de To-Do List, desenvolvida como parte da Atividade Prática Supervisionada (APS) do curso de Programação Web Front-End da Universidade Unicarioca. O sistema foi desenvolvido para se conectar a um servidor que foi fornecido pelo professor, utilizando os requisitos mínimos descritos no README na pasta `todo-list/server`.

## Descrição do Projeto

O sistema possui três páginas principais:

### 1-Página de login
O usuário pode acessar a plataforma usando um email e senha já cadastrados.
### 2-Página de cadastro
O usuário pode criar uma nova conta fornecendo um nome, email e senha.
### 3-Página de Gestão de tarefas(criação, visualização, edição e exclusão)
Após o login, o usuário pode criar suas tarefas, visualizar, edita-lás ou excluí-las.
